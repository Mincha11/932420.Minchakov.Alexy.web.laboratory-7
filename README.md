# Лабораторная работа №7
## Работа с базой данных SQLite и CRUD-операции

Вариант 5. Тема: «Фильмы» (рейтинг и жанр)
 1. Цель работы
Изучить основы работы с реляционными базами данных SQLite, реализовать CRUD-операции (создание, чтение, обновление и удаление записей) и интегрировать их с сервером Express.
 2. Описание проекта
Проект представляет собой веб-приложение для управления каталогом фильмов.
Для хранения информации используется база данных SQLite. Серверная часть реализована с помощью Node.js и Express.
Назначение файлов:

- `package.json` — настройки проекта и список зависимостей.
- `server.js` — создание сервера Express, подключение SQLite, создание таблицы и реализация API-маршрутов.
- `movies.db` — база данных SQLite, создаётся автоматически при запуске.
- `index.html` — веб-интерфейс для просмотра, добавления, изменения и удаления фильмов.
  3. Используемые технологии
- **Node.js** — среда выполнения JavaScript.
- **Express** — создание HTTP-сервера и маршрутов.
- **SQLite** — реляционная база данных.
- **sqlite3** — библиотека для взаимодействия с SQLite.
- **HTML и JavaScript** — создание пользовательского интерфейса.
- **Thunder Client** — проверка API-запросов.
 Реализованные API-маршруты
В проекте реализованы четыре основных CRUD-маршрута.
 GET  `/api/movies` Получение списка фильмов 
 POST `/api/movies`  Добавление нового фильма 
 PUT `/api/movies/:id`  Изменение информации о фильме 
 DELETE  `/api/movies/:id`  Удаление фильма 

Фильтрация и сортировка
При получении списка фильмов реализованы дополнительные возможности.
Фильтрация по жанру: GET /api/movies?genre=action
Фильтрация по минимальному рейтингу: GET /api/movies?minRating=7
 Пример добавления фильма
Для добавления фильма используется POST-запрос к адресу: http://localhost:4000/api/movies
Тело запроса в формате JSON:
json
{
    "title": "Interstellar",
    "genre": "sci-fi",
    "rating": 9.2,
